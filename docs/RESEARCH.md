# Reference research: Ragdoll Playground (Roblox)

> Target studied: <https://www.roblox.com/games/106521346673466/Ragdoll-Playground>
> Research date: 2026-11-08. Roblox.com, YouTube and the fan wikis are blocked from the build sandbox,
> so everything below comes from web-search summaries of code sites, fan wikis and store pages
> (sources at the bottom). No video link was attached to the request, so the "goal" layer of our
> game is designed from this research rather than from a specific video.

## 1. What the game is

| Fact | Detail |
|---|---|
| Live title | `[💉INJECTIONS] Ragdoll Playground` (it was earlier tagged `[👥 Multiplayer]` / `[👥UPD]`) |
| Developer | Speedwagon Gaming Foundation (group) |
| Created | 2026-09-27; last update 2026-11-04 |
| Scale | 15M+ visits in about 6 weeks; entered the Roblox charts 2026-10-29 |
| Genre | Simulation / Physics Sim, **2D ragdoll sandbox**, inspired by the Steam game *Granule* (Tevark) |
| Server size | 6 players |
| Pitch | Your own 2D ragdoll test dummy that you shoot, blow up, drop into lava or burn. |

The game is a Roblox take on the *People Playground* / *Granule* formula: a side-view sandbox where
the only "objective" is to do things to an indestructible ragdoll and watch the physics react.

## 2. Content categories

* **Weapons:** guns, swords, chainsaws, bombs, nukes.
* **Powers:** black hole, Chibaku Tensei, Almighty Push, gravity flip, tornado, meteors, acid, time stop.
* **Creatures:** zombies, aliens, skeletons, a dragon.
* **Materials:** sand, water, fire and lava that you can place and test against the dummy.
* **Injections (latest update):** syringes that apply effects to the dummy, the same idea as
  People Playground's syringes, where a needle keeps applying its effect while injected.
* **Maps:** about 17 rooms in the WORLD tab (for example a lava pit and a crusher).
* **Skins:** cosmetic dummy skins such as rainbow werewolf, pumpkin head, robot, alien, watermelon and snowman.

## 3. Controls and UI (desktop)

| Input | Action |
|---|---|
| Left click | Grab and fling |
| Right click | Use the equipped item |
| G | Slow motion |
| Space | Pause |
| H | Heal everyone (dummies stand back up, the scene is kept) |
| R | Reset the room (clears debris) |
| M | Menu |
| N | Spawn the last character |
| Z | Undo a spawn |
| K | Clear creatures |
| P | Photo mode |
| F1 | Show every keybind |

UI structure: a menu with tabs (**WORLD**: maps plus key hints, **Shop** with a **Codes** tab, item
categories). The room cap is **8 characters**, and the game shows a "too many characters" toast when
you hit it. The fan wiki sums up every session as a 4-beat loop: **pick something → use it → watch →
heal or reset → repeat.**

## 4. Monetization and live-ops

* **Game passes:** VIP 249 R$, Tools Pack 349 R$, Powers Pack 459 R$, Everything Bundle 499 R$.
  Everything named in the description is playable without paying.
* **Crate Spins:** random equipment, modifications and skins, earned without spending soft currency.
* **Codes tied to milestones:** `RELEASE`, `5KTHANKS!`, `15KTHANKS`, `30KTHANKS!`, `1MVISIT`, `10MVISITS`,
  `CUSTOM`. Rewards include powers (Black Hole, Almighty Push, Gravity Flip), rainbow skins and crate
  spins. Codes are posted in the description and the Discord, and they rotate every few days.
* **Update cadence:** the title tag changed roughly every 1–2 weeks (Multiplayer → Injections).

## 5. Why players get hooked and come back

1. **Instant, physical comedy.** Every input causes an over-the-top reaction within a second.
   Ragdoll physics never plays out the same way twice, so "one more try" never gets stale.
2. **A near-zero skill floor.** You click and things happen. There is no fail state and no reading.
   This fits the core Roblox audience (ages 9–14, short sessions, often on mobile).
3. **Emergent combinations.** Fire plus a tornado plus a black hole gives results the designer
   never scripted. Players ask "what if…?", which is the strongest intrinsic motivator in sandboxes.
4. **Collection and unlocks.** Powers, tools, skins and maps drip-feed novelty. Each new power is a
   new toy that refreshes the whole sandbox.
5. **Variable rewards.** Crate spins give unpredictable prizes, the same compulsion loop as loot boxes,
   kept to cosmetics and tools.
6. **Community milestone codes.** "Like the game so we hit 30K and drop a code." This turns players
   into marketers and pushes the like ratio, which feeds Roblox discovery. The many code-tracker
   sites also bring in a lot of search traffic.
7. **Clip-ability.** Slow motion, pause and photo mode exist to make funny, shareable clips
   (Medal.tv clips exist for the game). Shared clips bring in new players.
8. **Social chaos.** Up to 6 players can wreck the same dummy together, and friends join friends.
9. **Fast, visible live-ops.** Emoji title tags signal "something new", and returning players check
   the latest addition.

### Gaps we can improve on

* **No goal.** A pure sandbox loses players once the novelty fades, because there is nothing to
  aim for. We add challenges, trials, a discovery codex, ranks and a final "endgame" brew.
* **Thin progression.** Unlocks come from passes, spins and codes, so there is little you earn by
  playing. We add a crafting economy where you earn everything by playing and Robux only speeds it up.
* **Flat 2D presentation.** We keep the 2D side-view gameplay, but render it as **2.5D** with real
  3D lighting, materials, particles and post-processing, which looks much better.

## 6. What we adopt vs. change

| Keep (genre conventions) | Change (our original game) |
|---|---|
| Side-view sandbox, test dummy that can't die | Potion crafting and alchemy theme, original clay-golem test subject "Clayton" |
| Grab and fling, right-click to use | Potions you **brew**, then **throw** (splash) or **feed** (drink) |
| Slow-mo, pause, heal, reset, undo, photo mode | Same controls plus mobile buttons and gamepad support |
| Rooms/maps with hazards | 8 original labs (Alchemy Lab, Lava Forge, Crusher Works, …) |
| Character cap per room | 8 golems per lab, one private lab per player that others can visit |
| Codes, spins, passes, skins | Codes, Mystery Flask spins, passes, skins, daily rewards |
| Injections update (syringes) | 27 potions with **status combos** (burning + frozen = steam burst, frozen + impact = shatter, …) |
| — | **Goal:** discover every potion, clear the Grand Trials, brew the Philosopher's Elixir |
